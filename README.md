# Earnings-Daily

每天看一家公司财报，用大白话讲透。帮看我主页的人，把财报从天书读成故事。

One company's earnings a day, explained in plain language — so anyone can read a financial report like a story instead of a wall of numbers.

## 每篇怎么读（固定六段，3 分钟读完）

1. **一句话总结** — 这季这家公司是赚翻了还是在过冬
2. **核心数字** — 收入、利润、现金流，只挑最关键的
3. **钱从哪来、到哪去** — 业务结构和花钱的地方
4. **管理层说了啥** — 财报电话会里的关键原话和指引（guidance）
5. **风险和没说出口的** — 数字背后的雷
6. **下个季度看什么** — 跟踪清单
